# hello-world — Session 1 bootstrap

Your first DBAI repository. Everything in S1 happens **in the browser** — no
terminal, no AWS. You create this repo from the template, make small commits,
and prove the GitHub Actions workflow is green.

## Lab (in class)

1. **Use this template** to create your own **private** repository.
2. Add the professor as a **collaborator** and submit your **repository URL**.
3. Open **github.dev** (press `.` on the repo) and make your edits in the browser.
4. Watch the **Actions** tab: the `hello` workflow must be **green** on your push.

## Homework — fix the deliberate typo

This README ships with **one** deliberately marked typo. Your homework is to fix
it as a browser commit:

> Welcome to the DBAI course — this is your first repository.

Fix `frist` → `first`, commit it with a Conventional Commit message
(`fix: correct typo in README`), and confirm Actions stays green.

## Evidence to upload

Upload a screenshot of your green Actions run to
`evidence/s01-actions-green.png` (browser upload — no terminal). Record the same
step in `JOURNAL.md`.

## Rules

- **Conventional Commits** for every commit (`feat:`, `fix:`, `docs:` …) — at
  least **three** across the lab and homework.
- Keep `ABOUT.md` and `JOURNAL.md` current; the AI-use contract in `JOURNAL.md`
  is **signed** before you use any AI assistance.
- S1 ships **no** quality/release workflow, no solution test and **no** cloud
  credentials — you add those in later sessions.
